# 项目启动完整指南

> ⚠️ **重要前提**：必须先安装Node.js环境才能执行以下所有操作。如果没有安装Node.js，所有npm相关命令都会失败。

## 1. 安装Node.js环境

### 1.1 下载Node.js
1. 打开浏览器，访问Node.js官网：https://nodejs.org/zh-cn/download/
2. 选择"Windows Installer (.msi)"版本下载
3. 建议下载LTS（长期支持）版本，更加稳定

### 1.2 安装Node.js
1. 双击下载的`.msi`文件开始安装
2. 按照安装向导的指示进行操作：
   - 接受许可协议
   - 选择安装路径（建议使用默认路径）
   - 重要：确保勾选"自动安装必要的工具"选项
3. 点击"Install"开始安装
4. 安装完成后，点击"Finish"

### 1.3 验证安装
打开命令提示符（CMD）或PowerShell，输入以下命令验证安装：
```bash
node --version
npm --version
```
如果显示出版本号，说明安装成功。

## 2. 安装项目依赖

### 2.1 安装后端依赖
1. 打开命令提示符或PowerShell
2. 进入项目后端目录：
```bash
cd "C:\Users\风\Desktop\老年人健康智能助手\elderly-health-assistant\server"
```
3. 安装依赖：
```bash
npm install
```

### 2.2 安装前端依赖
1. 打开新的命令提示符或PowerShell窗口
2. 进入项目前端目录：
```bash
cd "C:\Users\风\Desktop\老年人健康智能助手\elderly-health-assistant\client"
```
3. 安装依赖：
```bash
npm install
```

## 3. 启动项目服务

### 3.1 启动后端服务
1. 在后端目录的命令窗口中执行：
```bash
npm start
```
或者使用开发模式（支持热重载）：
```bash
npm run dev
```
2. 后端服务默认运行在端口5000，您应该能看到类似以下的输出：
```
服务器运行在端口 5000
```

### 3.2 启动前端应用
1. 在前端目录的命令窗口中执行：
```bash
npm start
```
2. 前端应用默认运行在端口3000
3. 启动成功后，系统会自动打开浏览器访问 http://localhost:3000

## 4. 访问应用

- 后端API服务地址：http://localhost:5000
- 前端应用地址：http://localhost:3000

## 5. 可选：安装数据库（如需完整功能）

### 5.1 安装MongoDB
1. 访问MongoDB官网：https://www.mongodb.com/try/download/community
2. 下载Windows版本的MongoDB Community Server
3. 运行安装程序并按照提示完成安装
4. 启动MongoDB服务

### 5.2 安装Redis（Windows）
1. 访问GitHub仓库：https://github.com/microsoftarchive/redis/releases
2. 下载Windows版本的Redis
3. 解压并运行redis-server.exe启动Redis服务

## 6. 故障排除

### 6.1 常见问题
1. **权限问题**：如果安装或运行时遇到权限问题，请以管理员身份运行命令提示符
2. **端口占用**：如果提示端口被占用，可以修改.env文件中的PORT配置
3. **依赖安装失败**：可以尝试删除node_modules文件夹和package-lock.json文件后重新安装

### 6.2 环境变量检查
确保server/.env文件中配置正确：
```
# 服务器配置
PORT=5000

# 数据库配置
MONGODB_URI=mongodb://localhost:27017/elderly_health_assistant
REDIS_HOST=localhost
REDIS_PORT=6379

# DeepSeek API配置
DEEPSEEK_API_KEY=your-deepseek-api-key
DEEPSEEK_API_URL=https://api.deepseek.com/v1
DEEPSEEK_MODEL=deepseek-chat
```
