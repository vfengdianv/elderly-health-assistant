## 二、文档中真正的代码内容（按类别）

### 2.1 定义类：数据模型 / 接口 / 索引

- **`系统分析与设计文档.md`**
  - 总体架构图、前端/后端分层结构树（ASCII）
  - 6 个文档模型字段定义：`User`、`HealthProfile`、`Medication`、`DietPlan`、`ExercisePlan`、`Conversation`
  - 5 条索引 DDL：`db.users.createIndex({email:1},{unique:true})` 等
  - 22 条 API 清单（认证 / AI / 用药 / 饮食 / 运动）
  - 统一响应格式 `{success, message, data}`、鉴权头 `Authorization: Bearer <token>`
  - 开发/生产部署图与部署命令（`npm run build`、`npm install --production`、`pm2 start server.js`）
- **`项目计划书.md`**：9 张数据库表字段表（users、health_profiles、medication_reminders、diet_plans、exercise_plans 等，MySQL 字段类型）、四层架构图、微服务拆分（规划）

### 2.2 命令 / 配置类：安装、启动、部署

- **`项目启动指南.md`**：`node --version`、`npm install`、`npm start`、`npm run dev`、`server/.env` 配置块
- **`README.md`**：项目结构树、两组 API 清单、`node scripts/createAdmin.js`、`node scripts/seedDrugData.js`、双终端启动命令、`.env` 模板、5 段 curl 示例、默认管理员账号
- **`部署说明.txt`**：`node -v`、`net start MongoDB`、`node server.js`、`start.bat/start.ps1`
- **`deploy/部署指南.md`**：`ssh`、`git clone`、`chmod +x`、`./deploy.sh`、`cp ../deploy/生产环境.env .env`、`pm2 status/logs/restart`、`systemctl`、`mongosh`、`nginx -t`、`certbot --nginx`
- **`deploy/快速部署.md`**：上传/配置/部署/certbot 5 组命令

### 2.3 接口示例与代码片段类

- **`DIET_QUICK_START.md`**：`POST/GET/PUT/DELETE /api/diet/plans`、`GET /nutrition-stats`、`POST /advice` 的请求/响应示例
- **`BUG_FIX_REPORT.md`**：`Promise.race` 超时防护片段（与 `dietController.js` 实现一致）
- **`MEDICATION_MODULE_GUIDE.md`** / **`MEDICATION_IMPLEMENTATION_REPORT.md`** / **`QUICK_REFERENCE.md`**：用药接口请求/响应 JSON、`Medication` / `DrugInfo` 字段示例、curl 测试
- **`DIET_IMPLEMENTATION_REPORT.md`**：前端提交 payload 片段、`recharts` 引入方式、`npm install` 命令
- **`TESTING_GUIDE.md`**：`.env` 配置、`node quick-start.js`、`curl` 验证命令

## 三、项目实际代码结构

### 3.1 目录结构

```
elderly-health-assistant/
├── client/                          # React 18 前端（Create React App）
│   ├── public/index.html
│   └── src/
│       ├── App.js  index.js  App.css  index.css
│       ├── api/                     # axios 封装、认证 API
│       ├── components/
│       │   ├── ai/                  # AIAssistant
│       │   ├── auth/                # Login / Register / UserProfile / ProtectedRoute
│       │   ├── common/              # Header / Footer / Sidebar
│       │   ├── diet/                # DietPlan / NutritionTracker（Recharts）
│       │   ├── exercise/            # ExercisePlan / ExerciseTracker（Recharts）
│       │   └── medication/          # MedicationReminder / DrugInfo
│       ├── context/                 # AuthContext（全局登录状态）
│       └── utils/                   # storage（Token 存储）
├── server/                          # Node.js + Express 4 + Mongoose 7
│   ├── server.js
│   ├── config/                      # db.js、deepseek.js
│   ├── controllers/                 # ai / auth / diet / exercise / medication
│   ├── middleware/auth.js           # JWT 校验
│   ├── models/                      # User、Medication、DrugInfo、DietPlan、ExercisePlan、Conversation 等
│   ├── routes/                      # 5 个路由文件，共 32 条 REST 接口
│   ├── scripts/                     # 建管理员、种子药物、API 测试脚本
│   ├── utils/                       # helpers、validators
│   └── start.bat / start.ps1        # Windows 一键启动
├── deploy/                          # Nginx / PM2 / 部署脚本
├── docs/                            # 项目文档（本目录）
├── quick-start.js                   # 一键启动前后端
└── README.md
```

### 3.3 后端 API（实测 32 条）

| 模块 | 数量 | 端点 |
|------|-----:|------|
| 认证 | 7 | `POST /api/auth/register`、`POST /login`、`GET /current`、`GET|PUT /profile`、`POST /change-password`、`POST /logout` |
| 用药 | 7 | `/api/medication/reminders`（POST/GET/PUT/DELETE）、`/records`（POST/GET）、`/drug-info`（GET） |

| 运动 | 5 | `/api/exercise/plans`（POST/GET/PUT/DELETE）、`/stats` |

### 3.4 数据模型

| 模型 | 状态 |
|------|------|
| `User` | Mongoose 模型，bcrypt 密码加密（salt=10）、`comparePassword`、`toJSON` 隐藏密码、username/email 唯一索引 |
| `Medication` / `DrugInfo` | Mongoose 模型（用药提醒记录、药物信息库） |
| `DietPlan` / `ExercisePlan` | Mongoose 模型（四餐营养字段 / 运动计划字段） |
| `Conversation` | Mongoose 模型（AI 对话消息） |
| `HealthProfile` | 预留类，`validate/save/findByUserId` 为 TODO（未接入业务） |
