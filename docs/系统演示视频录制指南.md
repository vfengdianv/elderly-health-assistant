# 老年人健康智能助手 - 系统演示视频录制指南

## 📹 录制准备

### 1. 软件准备
- **录屏软件推荐**：
  - OBS Studio（免费开源）
  - Bandicam（专业录屏）
  - Camtasia（带编辑功能）
  
- **系统准备**：
  - 清理桌面，关闭无关程序
  - 启动前后端服务
  - 准备测试账号和数据

### 2. 录制参数设置
- **分辨率**：1920×1080 (Full HD)
- **帧率**：30fps
- **视频格式**：MP4
- **音频**：清晰的麦克风录音
- **时长**：建议10-15分钟

### 3. 测试数据准备
- 注册测试账号：`demo@example.com` / `123456`
- 准备3-5条用药提醒数据
- 准备2-3条饮食计划
- 准备2-3条运动计划
- 准备AI对话测试问题

## 📝 录制注意事项

### 1. 讲解技巧
- **语速适中**：不要太快，让观众能够跟上
- **声音清晰**：使用质量较好的麦克风
- **语调自然**：避免机械化朗读
- **适时停顿**：给观众消化信息的时间

### 2. 操作技巧
- **鼠标移动平滑**：不要突然跳跃
- **操作不要太快**：每个步骤都要展示清楚
- **等待加载**：AI回复等操作需要等待的，不要剪辑掉
- **展示效果**：悬停动画、成功提示等都要展示

### 3. 画面技巧
- **关闭通知**：录制前关闭系统通知
- **清理桌面**：不显示无关文件
- **浏览器干净**：关闭其他标签页
- **全屏显示**：F11全屏或隐藏浏览器地址栏

### 4. 后期处理
- **添加字幕**：关键操作步骤添加文字说明
- **添加箭头**：鼠标点击处可加箭头提示
- **背景音乐**：可添加轻柔的背景音乐（音量要低）
- **片头片尾**：添加标题卡片和感谢观看
