# 快速部署步骤

## 🚀 5分钟快速上线

### 1. 购买阿里云ECS（2分钟）
- 进入阿里云控制台 → 云服务器ECS
- 点击"创建实例"
- 选择配置：2核4G，CentOS 7.9
- 设置密码
- 配置安全组：开放 80、443、3000、5000 端口
- 完成购买，获取公网IP

### 2. 连接服务器（1分钟）
```bash
ssh root@你的服务器IP
# 输入密码
```

### 3. 一键安装环境（10分钟，自动执行）
```bash
# 上传 deploy 文件夹到服务器
# 或使用以下命令直接下载脚本：
curl -O http://你的文件地址/deploy.sh
chmod +x deploy.sh
./deploy.sh
```

### 4. 上传项目代码（2分钟）
使用 FTP 工具（如 FileZilla）上传项目到：
```
/home/elderly-health-assistant
```

### 5. 配置并启动（2分钟）
```bash
cd /home/elderly-health-assistant/deploy

# 配置环境变量
cp 生产环境.env ../server/.env
vi ../server/.env  # 修改域名

# 安装依赖
./setup.sh

# 配置 Nginx
sudo cp nginx.conf /etc/nginx/conf.d/elderly-health.conf
sudo vi /etc/nginx/conf.d/elderly-health.conf  # 修改域名
sudo nginx -t
sudo systemctl restart nginx

# 启动服务
./start.sh
```

### 6. 访问测试
浏览器打开：`http://你的服务器IP`

---

## 💡 常见问题

**Q: 访问不了网站？**
A: 检查安全组是否开放 80 端口

**Q: API 请求失败？**
A: 运行 `pm2 logs` 查看后端日志

**Q: 需要域名吗？**
A: 不需要，直接用IP也可以访问

---

## 📱 配置域名（可选）

如果有域名：
1. 域名解析：添加 A 记录指向服务器IP
2. 修改配置：
   - `/etc/nginx/conf.d/elderly-health.conf` 中的 `server_name`
   - `client/.env.production` 中的 `REACT_APP_API_URL`
3. 重启服务
