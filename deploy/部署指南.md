# 阿里云服务器部署指南

## 📋 部署清单

### 1. 购买服务器
- [ ] 登录阿里云控制台
- [ ] 购买 ECS 云服务器（推荐：2核4G，系统盘40GB）
- [ ] 选择系统：CentOS 7.9 或 Ubuntu 20.04
- [ ] 配置安全组：开放 80、443、3000、5000 端口
- [ ] 获取服务器公网IP

### 2. 连接服务器

使用 SSH 工具（如 PuTTY、Xshell）连接：

```bash
ssh root@your-server-ip
```

### 3. 上传项目文件

#### 方法一：使用 Git（推荐）
```bash
cd /home
git clone your-repository-url elderly-health-assistant
```

#### 方法二：使用 FTP/SCP 工具
使用 FileZilla 或 WinSCP 上传整个项目文件夹到 `/home/elderly-health-assistant`

### 4. 安装环境

```bash
cd /home/elderly-health-assistant/deploy
chmod +x *.sh
./deploy.sh
```

### 5. 配置环境变量

```bash
cd /home/elderly-health-assistant/server
cp ../deploy/生产环境.env .env
vi .env  # 编辑配置，替换域名和密钥
```

### 6. 安装依赖

```bash
cd /home/elderly-health-assistant/deploy
./setup.sh
```

### 7. 配置 Nginx

```bash
# 复制 Nginx 配置
sudo cp /home/elderly-health-assistant/deploy/nginx.conf /etc/nginx/conf.d/elderly-health.conf

# 编辑配置，替换域名
sudo vi /etc/nginx/conf.d/elderly-health.conf

# 测试配置
sudo nginx -t

# 重启 Nginx
sudo systemctl restart nginx
sudo systemctl enable nginx
```

### 8. 启动服务

```bash
cd /home/elderly-health-assistant/deploy
./start.sh
```

### 9. 验证部署

```bash
# 检查后端服务
pm2 status
pm2 logs elderly-health-backend

# 检查 Nginx
sudo systemctl status nginx

# 检查 MongoDB
sudo systemctl status mongod

# 访问测试
curl http://localhost:5000
```

### 10. 配置域名（可选）

如果您有域名：
1. 在域名服务商添加 A 记录，指向服务器公网IP
2. 修改 Nginx 配置中的 `server_name`
3. 重启 Nginx

### 11. 配置 HTTPS（可选但推荐）

使用 Let's Encrypt 免费证书：

```bash
# 安装 certbot
sudo yum install -y certbot python3-certbot-nginx || sudo apt-get install -y certbot python3-certbot-nginx

# 自动配置证书
sudo certbot --nginx -d your-domain.com

# 自动续期
sudo certbot renew --dry-run
```

## 🔧 常用命令

### PM2 进程管理
```bash
pm2 list                    # 查看所有进程
pm2 logs elderly-health-backend  # 查看日志
pm2 restart elderly-health-backend  # 重启服务
pm2 stop elderly-health-backend     # 停止服务
pm2 delete elderly-health-backend   # 删除进程
```

### MongoDB 管理
```bash
sudo systemctl start mongod    # 启动
sudo systemctl stop mongod     # 停止
sudo systemctl status mongod   # 状态
mongosh                        # 连接数据库
```

### Nginx 管理
```bash
sudo nginx -t                  # 测试配置
sudo systemctl restart nginx   # 重启
sudo systemctl status nginx    # 状态
sudo tail -f /var/log/nginx/elderly-health-error.log  # 查看日志
```

## 🚨 故障排查

### 1. 无法访问网站
- 检查服务器安全组是否开放 80、443 端口
- 检查防火墙：`sudo firewall-cmd --list-all`
- 检查 Nginx 状态：`sudo systemctl status nginx`

### 2. API 请求失败
- 检查后端服务：`pm2 logs elderly-health-backend`
- 检查端口占用：`netstat -tulpn | grep 5000`
- 检查 MongoDB：`sudo systemctl status mongod`

### 3. 数据库连接失败
- 检查 MongoDB 状态
- 检查 .env 配置
- 查看日志：`sudo tail -f /var/log/mongodb/mongod.log`
