老年人健康智能助手 - 部署说明

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

一、系统要求

1. 软件环境
   • Node.js >= 14.0.0
   • MongoDB >= 4.0
   • npm（Node.js 自带）

2. 推荐操作系统
   • Windows 10/11
   • macOS 10.15+
   • Linux (Ubuntu 18.04+)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

二、快速启动（最简单方式）

如果你已经完成了一次性配置，只需双击运行：

Windows:
  双击 start.bat

或使用 PowerShell:
  右键 start.ps1 -> 使用 PowerShell 运行

然后打开浏览器访问：
  http://localhost:5000

三、详细安装步骤

步骤 1：安装 Node.js

1. 访问 https://nodejs.org/
2. 下载 LTS 版本（推荐 18.x 或 20.x）
3. 运行安装程序，一路点击"下一步"
4. 安装完成后，打开命令提示符，输入：
   node -v
   如果显示版本号（如 v18.17.0），说明安装成功

步骤 2：安装 MongoDB

1. 访问 https://www.mongodb.com/try/download/community
2. 下载 MongoDB Community Server
3. 运行安装程序
4. 安装完成后，启动 MongoDB 服务：
   • Windows： services.msc 中找到 MongoDB Server，右键启动
   • 或运行：net start MongoDB

步骤 3：配置环境变量

1. 进入 server 目录
2. 找到 .env 文件，用记事本打开
3. 检查以下配置是否正确：

   PORT=5000
   MONGODB_URI=mongodb://localhost:27017/elderly_health_assistant
   
   DEEPSEEK_API_KEY=your-deepseek-api-key
   DEEPSEEK_API_URL=https://api.deepseek.com/chat/completions
   DEEPSEEK_MODEL=deepseek-chat

   注意：DEEPSEEK_API_KEY 是你的 DeepSeek API 密钥，如需更换请修改

步骤 4：安装后端依赖

1. 打开命令提示符
2. 进入 server 目录：
   cd server
3. 安装依赖：
   npm install

步骤 5：启动服务器

1. 在 server 目录下，运行：
   node server.js
   
   或使用一键启动脚本：
   Windows: 双击 start.bat
   PowerShell: .\start.ps1

2. 看到以下提示表示启动成功：
   ✅ MongoDB 数据库连接成功
   ✅ 服务器运行在端口 5000
   📱 请访问 http://localhost:5000

3. 打开浏览器，访问 http://localhost:5000

四、常见问题

问题 1：提示 "MongoDB 连接失败"

解决：
1. 检查 MongoDB 服务是否已启动
2. 检查 .env 文件中的 MONGODB_URI 是否正确
3. 如果 MongoDB 未安装，请参照步骤 2 安装

问题 2：提示 "未提供认证 Token"

解决：
这是正常的安全机制，请先注册账号并登录

问题 3：AI 助手无法回复

解决：
1. 检查 .env 文件中的 DEEPSEEK_API_KEY 是否正确
2. 检查网络连接是否正常
3. 如果 API 密钥已过期，请前往 https://platform.deepseek.com/ 获取新密钥

问题 4：端口 5000 被占用

解决：
1. 修改 .env 文件中的 PORT 值，如 PORT=3001
2. 或关闭占用 5000 端口的程序

六、更新前端代码后重新构建

如果你修改了前端代码，需要重新构建：

1. 进入 client 目录：
   cd client

2. 安装依赖（首次需要）：
   npm install

3. 构建生产包：
   npm run build

4. 将 build 目录复制到 server/public：
   xcopy /E /I /Y build ..\server\public

5. 重新启动服务器
